About me

A passionate
IT student

Hi! I'm Kurt, a BSIT student at Pamantasan ng Lungsod ng Valenzuela. I have a passion for technology, coding, and design — and I'm always looking for ways to combine both.

On the technical side, I have a strong foundation in Java, Python Flask, C# ASP.NET, HTML, Tailwind CSS, and is proficient in using tools like Visual Studio, VS Code, XAMPP, and SQL Server Management Studio, which lets me build and manage web applications and databases effectively.

On the creative side, I have used Adobe Illustrator, Photoshop, Figma, and Canva for graphic and UI design, CapCut and DaVinci Resolve for video editing. This mix of coding and design lets me build things that are both functional and visually polished.

I'm always eager to learn, adapt, and grow in the ever-evolving tech industry.
